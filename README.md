# 🎓 Anna University COE Notification Portal

A modern, responsive notification portal for **Anna University – Controller of Examinations (COE)**.

The portal provides students with quick access to the latest examination-related notifications, circulars, results, timetables, and other important updates published by the Anna University Controller of Examinations.

🔗 **Live Website:**  
https://dhinakaranelango.github.io/anna-coe-notifications/

---

## 📌 About the Project

The **Anna University COE Notification Portal** is designed to make examination-related announcements easier to find and access.

Instead of manually checking the official COE website frequently, students can use this portal to view the latest notifications in a simple and mobile-friendly interface.

### ✨ Features

- 📢 Latest COE notifications
- 📝 Examination notifications
- 📊 Results updates
- 📅 Timetable updates
- 📜 Circulars
- 🔔 Important announcements
- 🔍 Search notifications
- 🏷️ Category-based filtering
- 🌙 Dark mode
- 🔄 Refresh notification database
- 📱 Fully responsive mobile design
- 🔗 Share individual notifications
- 🟢 Live COE monitoring status
- 📆 Today's update counter
- 📄 Direct access to official notifications
